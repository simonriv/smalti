# F7.5 · Guardas para agentes — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (modo nativo, `.claude/rules/workflow.md`). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** el CLI de Smalti, llamado desde el hook `PreToolUse` del plugin, deniega las lecturas de secretos y retiene los comandos destructivos hasta que Simón los aprueba en una tarjeta nativa. Si algo falla, el hook falla cerrado. Además, Smalti escribe las reglas `permissions.deny` del proyecto.

**Architecture:** las reglas son dominio puro en `SmaltiCore/Domain/Guard` y los casos de uso son `ScreenToolUse`, `AgentApprovals` y `ProtectProjectSecrets`, con dos puertos nuevos (`GuardRequests` y `ProjectPermissions`). Los adaptadores son estos:

- el CLI `smalti guard` y el `kind: "guard"` del socket, en `IPCAdapter`;
- `ClaudeProjectPermissions` y la versión del plugin instalado, en `ClaudeHarnessAdapter`;
- `GuardsReader`, en `TOMLConfigAdapter`.

La app solo conecta, pinta la tarjeta y enruta los atajos.

**Tech Stack:** Swift 6 (concurrencia estricta), Swift Testing, XCUITest, sockets Unix y `DispatchSemaphore`, `JSONSerialization`, Python 3 para el servidor falso de la medición.

**Spec:** `docs/specs/F7.5-guardas.md`

## Global Constraints

- `SmaltiCore` sin AppKit, SwiftUI, Combine, Darwin ni SDKs; la guarda de imports no se toca.
- Plazos: app 600 s (`AgentApprovals.standardTimeout`), CLI 630 s (`GuardCommand.deadline`), hook `timeout: 660` con `onFailure: "block"`; servidor 620 s por conexión; 32 peticiones en espera como máximo.
- Comando o ruta de `tool_input` hasta 65 536 bytes; uno mayor → `ask` (destructivo «comando demasiado largo para revisarlo»).
- JSON de denegación exacto: `{"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"deny","permissionDecisionReason":"<motivo>"}}`; aprobar = salida 0 sin nada en stdout.
- Textos de interfaz y motivos, tal cual la spec («Textos nuevos»). El redactado es `•••`.
- Atajos: `guard.approve` ⌘⇧↩ (`chord("enter", .shift, .command)`), `guard.reject` ⌘⇧⎋ (`chord("escape", .shift, .command)`).
- Plugin `0.2.0`; CLI `smalti 0.2.0`; app 0.7.5.
- Errores tipados con operación, dato y causa; sin `!`, `try!`, `as!` ni `unsafe*` sin comentario.
- Ningún `Logger` publica comandos, rutas ni hosts (`privacy: .private`).
- Pruebas:
  - nunca `~/.claude`, `~/.config/smalti` ni un `.claude/settings.local.json` real; nunca un Claude real ni una base de datos o API real;
  - shells con `/bin/zsh -f`;
  - UI por `scripts/check-daily-untouched.sh` con `SMALTI_DAILY_PID`, una sola corrida a la vez y la app con `env -i`.
- `swift format lint --strict` con la línea de `CLAUDE.md`.
- Commits: Conventional Commits en inglés, con el trailer de la sesión.

## Review Focus

1. **Comillas y escapes que parten una ruta** (`cat .e"n"v`, `cat '.env'`, `cat .env\ `): el lexer junta las partes como un shell → prueba `quotedPartsJoinIntoOnePath` (T1).
2. **Varias herramientas en paralelo en el mismo panel**: dos peticiones en cola; aprobar resuelve solo la primera y la tarjeta pasa a «1 de 1» → `approveResolvesOnlyTheOldest` (T5).
3. **El panel se cierra o la app sale con peticiones pendientes**: todas se deniegan con su motivo y el CLI sale → `closingPaneDeniesItsRequests` (T5) y `appStopDeniesOpenConnections` (T7).
4. **Una regla legítima con mayúsculas o una ruta absoluta** (`/opt/homebrew/bin/terraform DESTROY` no es una orden válida, pero `/opt/homebrew/bin/terraform destroy` sí): se compara por nombre base y el subcomando es exacto → `fullPathProgramMatches` (T3).
5. **`settings.local.json` con comentarios o comas finales** (JSON inválido para Foundation): ⌘K no lo sobrescribe y lo dice → `unreadableSettingsAreLeftUntouched` (T8).
